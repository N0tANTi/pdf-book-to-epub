# 《书名》校对规则

> 用法：复制本模板为 `规则/书名.md`，先抽 5–10 页跑一遍 step1+step2，
> 对照原书填写下面各项，再交给 step3。规则写得越具体，校对越稳。

## 1. 标题层级映射（必填）

| 原书样式 | Markdown 级别 |
|---|---|
| 第X部分 / 第X编 | # (H1) |
| 第X章 | ## (H2) |
| 一、二、三、 | ### (H3) |
| （一）（二） | #### (H4) |

- 目录页：整体删除 / 保留为普通文本（二选一，EPUB 会自动生成目录）
- 章首页可能有的引言/题词：格式化为 > 引用块

## 2. 注释/脚注处理（必填，这是最容易乱的部分）

- 脚注标记样式：①②③ / [1] / 上标数字（写清楚是哪种）
- 脚注内容位置：页面底部 / 章末 / 书末
- 处理方式：统一转为 Markdown 脚注语法 `[^页码-序号]`，脚注内容集中放在所属章节末尾
- 译注 vs 原注的区分标记（如"——译者注"）：保留原文标记，不合并

## 3. 引文与特殊排版

- 大段引文（原书缩进/变字体）：转为 > 引用块
- 着重号/黑体强调：转为 **加粗**
- 书名号内的外文书名：保持原样，不加斜体

## 4. 已知的 OCR 高发错误（跑过抽样后补充）

- 例：本书"存在"常被认成"存左"—— 只标记，不修改
- 例：希腊文单词全部标记为疑似

## 5. 页眉页脚特征（step2 没删干净时补充）

- 页眉样式：奇数页为章名 / 偶数页为书名
- 额外正则：（填给 step2 的 --header-pattern）

## 6. 铁律（不要删除这部分）

- 只做结构操作，禁止改动任何正文字词
- 疑似识别错误只列入 SUSPECTS，不修改
- 无法判断的地方保持原样并列入 SUSPECTS
